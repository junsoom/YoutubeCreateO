# 파일404 · #011 저지 데빌 — 도시 하나가 일주일 동안 문을 닫은 사건

조사: 2026-10-30 · 형식: 쇼츠(60초) + 롱폼(8~10분)
**이 편의 축은 '괴물'이 아니다.** 1909년 1월 16~23일, 뉴저지와 펜실베이니아 일대에서 학교와 공장이 실제로 문을 닫았다.
괴물이 진짜였는지는 끝내 알 수 없지만, **패닉은 문서로 남아 있다.** 그 대비가 이 영상의 전부다.

## 2. 사실 정리

### 2-1. 파인배런스 — 사건이 일어난 땅
| 표시 | 내용 | 출처 |
|---|---|---|
| ✅ | 뉴저지 남부의 **대서양 연안 소나무 황무지**. 모래가 많고 산성인 데다 **영양분이 없어** 유럽 이주민이 농사를 지을 수 없었다. 그래서 '배런스(불모지)' | WP |
| ✅ | 1978년 미국 **최초의 국가보호구역(National Reserve)**으로 지정, **110만 에이커**(약 4,500km²) — **뉴저지 땅의 22%**, 7개 카운티에 걸침 | WP |
| ✅ 🔥 | **필라델피아와 뉴욕 사이, 미국에서 가장 인구가 빽빽한 회랑 한가운데**인데 비어 있다. 1969년 기준 파인배런스 인구밀도는 1제곱마일당 **15명**, 바로 옆 땅은 **1,000명** — **66배 차이** | WP |
| ✅ | 지하에 **커크우드-코한지 대수층**, 17조 갤런. 미국에서 가장 깨끗한 물 중 하나 | WP |
| ✅ | 산불이 생태의 일부다. 리기다소나무는 **껍질을 뚫고 다시 싹이 나고**, 솔방울은 **불에 데워져야 열린다**. 불이 잦은 곳에는 키 1.2m도 안 되는 **난쟁이 소나무 평원**이 생긴다 | WP |
| ✅ | 식민지 시대 산업: 늪지 철광(약 35개 용광로, 배스토·앳시온·행오버 등), 숯, 유리, 대서양흰삼나무 벌목, 송진·타르. 1869년 늪지 철 산업이 끝나자 숲이 전부 되삼켰다 → 지금도 **유령 마을**이 남아 있다 | WP |
| ✅ | 18~19세기 파인배런스 거주민은 "사회의 찌꺼기"로 취급됐다: 가난한 농부, 도망자, 노상강도(파인 로버스), 원주민, 밀렵꾼, 밀주업자, 도망 노예, 탈영병 | W |
| ✅ | 주민을 가리키는 말 **'파이니(piney)'**는 멸칭이었다. 1859년 *Atlantic Monthly* 기사(W.F. Mayer, "In the Pines")는 이 지역을 "**야만에 있어 원시적**"이라 쓰고 주민을 "토리당의 타락한 후손… 무지에 완전히 절고 짐승 같은" 이라 불렀다 | R |
| ✅ 🔥 | 20세기 초 **우생학** 연구가 파이니를 "선천적 백치와 범죄자"로 그렸다 — 헨리 고다드의 **'칼리칵 가족'** 연구. **지금은 편향·부정확·비과학적이며 조작일 가능성이 높다고 평가된다** | W, WP |
| ✅ | 파이니 스스로 무서운 이야기를 퍼뜨려 외지인을 쫓아냈다는 설명이 있다 (밀주·밀수에 유리했다) | W, NJPB |
| ✅ | 파인배런스의 다른 전설들: 캡틴 키드의 유령, **블랙 닥터**(인종 때문에 개업을 못 하고 숲에 들어가 진료한 흑인 의사의 혼령), 블랙 독, 금발 소녀, 흰 수사슴, **블루 홀** | W, WP |

### 2-2. 1735년 '어머니 리즈의 열세 번째 아이' — 전설 쪽
| 표시 | 내용 | 출처 |
|---|---|---|
| 👻 | 가장 널리 퍼진 판본: 1735년, **리즈라는 여자**에게 아이가 열둘 있었다. 열세 번째를 가진 걸 알고 **"이 아이는 악마가 되어라!"**고 외쳤다. 아이는 정상으로 태어났다가 곧 날개·꼬리·발굽이 돋고, 방 안 사람들을 꼬리로 후려친 뒤 **굴뚝으로 날아올라** 소나무 숲으로 사라졌다 | W, R |
| 👻 | 변형들: 어머니 리즈가 **마녀**였고 아버지는 악마 본인이었다 / 산파를 죽이고 달아났다 / 성직자들이 **엑소시즘**을 시도했다(1740년에 100년간 봉인했다는 판본) | W, INQ19, DV |
| 👻 | 장소 변형: **리즈 포인트**(대서양 카운티), **벌링턴**, **에스텔빌**(메이스랜딩 근처, 1855년경 판본), **쉬라우즈 집** | W, DV |
| ⚠️ | 어머니 이름도 제각각이다: Leeds / Shourds(Shrouds) / Jane / Deborah / Janet. **어느 판본도 1차 사료로 확인되지 않는다** | W, DV, R |
| ✅ 🔥 | **Regal: 퀘이커는 엑소시즘을 하지 않는다.** '성직자가 쫓아냈다'는 이야기는 문헌 근거가 없다 | R |
| ✅ | Regal: 기형아 출생설도 근거 없음. **벌링턴 지역의 당시 출판물·의사 기록에 그런 출생 기록이 없다** | R |
| ✅ 🔥 | 흔히 인용되는 **1790년 '밴스 라너(Vance Larner)의 일기'** — 여러 연구자가 원본을 찾지 못했다. **현재로선 날조로 봐야 한다** | R |
| ⚠️ | '1735년'의 출처: McMahon(1973)이 민속학자 **프레드 맥패든**이 1735년 벌링턴 문헌에서 '악마' 언급을 찾았다고 전한다. **그러나 두 사람 다 인용 근거를 내놓지 않았다.** 맥패든 본인도 그 '악마'가 지금의 저지 데빌인지 **확신하지 못했다** | R, SK |
| ✅ | 당시 '벌링턴'은 도시 이름이 아니라 **벌링턴 시에서 대서양까지의 넓은 지역**을 가리켰다 → 리즈 포인트·에스텔빌 판본과 같은 곳일 수 있다 | DV, SK |
| ✅ | **문헌에 남은 가장 이른 '리즈 데빌' 언급은 1859년 5월 *Atlantic Monthly*** (W.F. Mayer, "In the Pines") — 파이니들이 믿는 이야기로 지나가듯 적혀 있다. **역시 출처 표기가 없다** | R |
| 📰 | 1887년 신문: "그건 새도 짐승도 아니고 **리즈 데빌**이다. 100년 전 벌링턴 카운티 **에브샴**에서 태어났다. … 개와 사람이 쫓고 남부 저지 최고의 명사수들이 쏘았지만 죽일 수 없었다. **벌링턴과 인근 카운티에 리즈 데빌을 모르는 집이 없고,** 내가 어릴 적엔 아이들 겁줄 때 쓰는 도깨비였다" | W |
| ✅ | 1905년 *Trenton Times* (7/15) "The Devil was Bordentown Born" — 여기선 **원숭이 같은 생물**이고, 바로 날아가지 않고 **몇 해 동안 가족과 살다가** 굴뚝으로 나간다. 사건 연도도 **1808년** | R |

## 6. 대본 원칙 (이번 편)

1. **축을 흔들지 않는다.** 이 편은 괴물 생김새 자랑이 아니라 **"일주일 동안 도시가 멈춘 사건"**이다. 괴물 묘사는 전체의 3분의 1을 넘기지 않는다.
2. **사실과 전설을 문장 끝에서 가른다.**
   - ✅ → "문을 닫았습니다", "실렸습니다", "~라고 적혀 있습니다"
   - 📰 → "~라고 **신문에 말했습니다**", "~라고 **진술했습니다**" (증언이 실린 건 사실, 내용은 미확인)
   - 👻 → "~라고 **합니다**", "~라는 **이야기가 전해집니다**"
   - ⚠️ → 한쪽만 말하지 말고 **둘 다 말하거나, 애초에 쓰지 않는다**
3. **날짜는 요일로 말한다.** 1909년 1월 16~23일이라는 **주(週)**는 확실하지만, 개별 목격의 날짜는 2차 자료마다 하루씩 다르다. 날짜를 못 박는 건 **Inquirer 지면(1/21, 1/22, 1/23, 1/24)**뿐.
4. **필라델피아 동물원 현상금을 사실처럼 말하지 않는다.** "1만 달러 현상금이 걸렸다고 **소문이 돌았습니다**. 그런데 2026년에 신문사가 동물원에 확인해 보니, **1909년 회의록 어디에도 그런 기록이 없었습니다.**" ← 이 구조가 오히려 더 세다.
5. **제프리스의 조작을 '정답'으로 포장하지 않는다.** 그는 불에 기름을 부었지, 불을 붙인 게 아닐 가능성이 크다(1908년 발자국 사진). 마지막은 Skeptoid처럼 **"우리는 모른다"**로 닫는다. 억지 결론이 가짜 다큐를 만든다.
6. **파이니를 비웃지 않는다.** '칼리칵 가족' 우생학 연구는 **편향되고 조작됐을 가능성이 높다고 평가된다**. 이 편에서 파인배런스 주민은 **괴물의 배경이 아니라 피해자 쪽**에 가깝다. 반드시 한 문장 넣는다.
7. **캥거루는 실존했던 동물이다.** 구리판 날개를 붙이고 막대기로 찔린 채 전시됐다. 로지(#006) 편과 같은 결로, **웃고 끝내지 않고 한 박자 쉰다.** ("그 캥거루가 어떻게 됐는지는 아무 기록도 없습니다.")
8. **리즈 가문 실명은 써도 된다.** 전부 300년 전 공개 인쇄물에 남은 이름이다(대니얼·타이탄·야펫). 1909년 목격자 실명(넬슨 에번스, E.W. 민스터, 제임스 새크빌, E.P. 위든)도 **당시 신문에 공개 보도된 이름**이라 쓸 수 있다.
9. **재현 표기.** 캥거루 사진, 눈 위 발자국 사진, 와이번 도해, 1900년대 거리·공장 사진은 전부 **'재현' 또는 촬영연도 자막**을 단다. 1909년 당시 사진이 아닌 것을 1909년인 척 쓰지 않는다.
10. **#005 모스맨과 겹치지 않게.** 붉은 눈 연출(`events.eyes`) 금지, '올빼미 오인'은 **1887년 독자투고**라는 다른 각도로 들어간다("22년 먼저 답이 나와 있었다"), 다리·참사 같은 실제 사망 사건이 없으므로 톤은 **공포보다 블랙코미디 쪽으로 반 발짝**.
