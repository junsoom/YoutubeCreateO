# 파일404 스타일 가이드 (v1, 2026-10-30)

> 주 사례 분석 대상: **기묘한 밤 (@기묘한밤, 구독자 115만)**. 다른 채널은 짧게 참고.
> 근거: 실제 자막(유튜브 자동 자막)과 조회수(yt-dlp, 2026-10-30 수집). 다른 채널 대본은 복사하지 않고, 패턴만 뽑았다.
> 아래 '예시'는 패턴을 보여 주는 짧은 인용이거나 우리가 새로 쓴 문장이다.
> 자동 자막이라 고유명사 오타가 있다 (예: 모스맨 → '모수면'). 인용은 뜻만 맞춰 옮겼다.

## 0. 한눈에 보는 핵심 규칙 (먼저 읽기)

1. **첫 문장 = 날짜 + 장소 + 평범한 일상**, 또는 **결과부터 말하기**. 채널 인사, "여러분" 같은 말로 시작하지 않는다.
2. **말하는 속도는 초당 5.5~6.0음절**. 쇼츠 대사는 **290~330음절**로 쓴다 (모스맨 #001은 255음절/62초 ≈ 4.1음절/초라 기묘한 밤 쇼츠보다 약 25% 느슨하다).
3. **문장 끝맺음 비율 ≈ ~습니다 55% / ~죠 20% / ~는데요 20% / 질문 2~5%**. "~는데요"는 반전 직전에, "~죠"는 한 단락을 닫을 때 쓴다.
4. **목격 장면은 재연 내레이션(현재형) + 1인칭 증언 인용**으로 만든다. 인용 앞에는 "훗날 ○○는 이렇게 말했습니다" 같은 예고를 붙인다.
5. 사건이 커지는 순서를 지킨다: **첫 목격 → 같은 날 두 번째 목격 → 이름이 붙음 → 목격이 퍼짐 → 참사와 연결 → 세계 곳곳 → 해석들 → 과학 반론 → 반론의 빈틈 → 현대 목격 → 질문으로 끝**.
6. **과학 반론은 영상의 65~80% 지점**에 한 번 넣고, 곧바로 **"하지만 이것으로는 ~를 설명할 수 없었습니다"**로 미스터리로 되돌아온다.
7. **말로 하는 구독 요청은 하지 않는다** (기묘한 밤 롱폼 8편 자막에서 '구독/좋아요/알림'은 0회였다). 대신 고정 끝인사를 쓴다 → 우리는 "파일404, 기록을 닫습니다." (시그니처) + 화면 글리치.
8. 제목: **[언제·어디서] + [발견·포착·목격]된 + ['고유한 이름' 또는 정체불명의 ○○]**. 롱폼은 끝에 **[미스터리] / [사건사고] / [괴담]** 같은 분류 꼬리표를 붙인다.
9. 주제: 기묘한 밤 데이터에서는 **한국과 엮인 이야기, 미군·정부가 숨겼다는 이야기, 크기나 사망자 수가 큰 이야기**가 서양 괴물 단독 주제(모스맨 25만 회)보다 5~10배 많이 봤다.

### 1-2. 말투와 문장 끝맺음

자막을 문장 단위로 나눠 센 결과 (자동 자막이라 대략적인 값):

| 영상 | 문장 수 | 문장 길이 중앙값 | ~ㅂ니다 | ~죠 | ~는데요 | ~어요(인용) | ~까요 |
|---|---|---|---|---|---|---|---|
| 모스맨 w6UHctJ-cBs | 86 | 35음절 | 46 (53%) | 18 (21%) | 16 (19%) | 4 | 2 |
| MH370 UFlbDD3PRUs | 77 | 35음절 | 43 (56%) | 18 (23%) | 15 (19%) | 0 | 1 |

어미마다 하는 일:
- **~습니다 / ~합니다 / ~됩니다 (현재형)**: 사실을 전하고 장면을 진행한다. 과거 사건도 현재형으로 말해 지금 일어나는 일처럼 들리게 한다.
  예) "~야간 드라이브를 나섰습니다 … 무언가를 목격하게 됩니다 … 재촉합니다"
- **~는데요**: 다음 문장에 반전이나 정보가 온다는 신호다. 바로 뒤에 "~때문이죠" 또는 놀라운 사실이 온다.
  예) "얼음처럼 굳어버리고 말았는데요 → 마당에는 … 짐승이 있었기 때문이죠"
- **~죠**: 한 단락을 닫거나 이유를 확인한다 ("~때문이죠", "~사라져 버리고 말았죠").
- **~라고 합니다 / ~다고 하죠 / ~다고 주장했습니다**: 전설과 주장에 쓴다. 증언에 기대는 '거인' 편에서는 '~다고 (합니다/하죠/했습니다)'가 20회 나왔고, 기록이 확실한 MH370 편에서는 0회였다. **확실한 정도에 따라 어미를 바꾼다.**
- **~까요?**: 끝에서 1~2번만 쓴다.

리듬 단어 (모스맨 편 10분 기준): 그런데 3 · 하지만 4 · 그러나 1 · 놀라운 것은/놀랍게도 2 · "기이한 것은" 1 · "더욱 충격적인 것은"(쇼츠). 고르게 흩어 쓰고, 한 단락에 하나만 쓴다.

### 1-4. 목격 장면을 극적으로 만드는 방법

1. **재연 내레이션**: 등장인물 이름, 자리, 행동을 구체적으로 적는다. 예: 남편이 운전, 아내는 옆자리, 개 이름 '밴딧', TV 지지직, 가스 밸브. **평범한 일상을 먼저 자세히 보여 준 다음 이상한 것 하나를 넣는다.**
2. **감각 묘사는 하나씩**: 소리(쿵, '키키' 하는 울음) → 빛(붉은 안광) → 모양(머리가 없고 가슴에 눈) → 크기(성인 남성보다 큼) 순서다. 한 문장에 감각 하나만 쓴다.
3. **1인칭 증언 인용**: "훗날 ○○는 그 순간을 이렇게 이야기했습니다." → 해요체 1인칭 인용 ("~본 적이 없었어요", "~줄로만 알았습니다"). 인용은 2~3문장이고, 롱폼 한 편에 3~5번 나온다.
4. **문서로 남은 증언은 '-다'체로**: "다음은 ○○ 씨와 아이들이 증언한 내용입니다." → "비행체가 떠올랐다. 은색으로 빛나며 회전했다. 그대로 사라져버렸다." 짧은 '-다' 문장 3~4개를 이어 붙인다 (낙동초 편).
5. **번역했다는 표시**: 외국 증언을 옮길 때는 "번역한 실제 증언입니다"라고 밝힌다 (거인 편). → 우리는 화면에 '증언 재구성' 또는 '번역' 자막을 띄운다.
6. **목격담을 한데 모아 보여 주기**: "목격담은 비슷했습니다. ~보았다. ~활강했다. ~노려보았다." 짧은 구절 세 개로 몽타주를 만든다.
7. **같은 시각, 다른 곳**: "같은 날 밤, 비슷한 시각." 서로 모르는 두 목격자가 같은 것을 봤다는 이야기로 신빙성을 키운다 (모스맨, 낙동초 둘 다 이렇게 했다).

### 1-5. 단락을 잇는 장치 (열린 고리)

- 콜드오픈(약 60초)이 끝나고 음악으로 넘어간 뒤 첫 문장: **"그러나 ○○에 대한 목격담은 이제 막 시작된 것이나 다름없었습니다."** → 앞으로 더 있다고 약속하는 문장이다.
- 단락이 끝날 때 **"그런데"**: "그런데 ○○가 목격된 그날, ~가 무너지며 46명이 숨집니다."
- 끝난 줄 알았는데 다시 시작: "~한순간에 뚝 끊겨버렸죠. 그런데 이후 세계 곳곳에서 …" / "~서서히 잊혀져 가는 듯 보였죠. 그러던 2013년, …"
- 강조 장치: "기이한 것은 ~라는 것이죠", "놀라운 것은 ~", "더욱 충격적인 것은 ~"
- **열린 고리는 단락마다 하나만** 연다. 다음 단락 첫 2문장 안에 바로 답한다.

다른 편들도 거의 같다:
- **거인 편 (306만)**: 성경 인용으로 시작 → 제보 → 두 번째 독립 증언 → 작전 재연 (알파팀 실종 → 동굴 → 거인 출현 → 30초 교전) → 은폐 (비밀유지 서약) → 수송 조종사의 '-다'체 증언 → 신장·무게 숫자 → 고대 방패와 연결 → 원주민 신앙 → 2019년 새 제보 → 질문으로 끝.
- **낙동초 편 (223만)**: 1973.4.13 날짜로 시작 → 22명 동시 목격 → 그림을 그려 일치 확인 → 따로 있던 두 아이의 일치 → "착륙했다" 신고 → 주민 30명 → 특징 정리 → 교수가 방사능을 쟀지만 이상 없음 (반론, 76%) → 정부가 무시 → 'UFO로 인정되는 조건'에 맞는다 → 질문으로 끝.
- **줄리아 편 (158만)**: 큰 화두(바다는 미지)로 시작 → 소리 감지 → 과학자들이 현실적 가능성을 먼저 검토 (35%) → 반박 → 거대 생물이라는 주장 → 고래 소리 가설 (80%) → "지속성은 설명 못 함" → 끝.

### 1-7. 과학 반론을 넣는 위치와 방식

- 위치: **영상의 65~80%** (모스맨 66~77%, 낙동초 76%, 줄리아 80%; 이무기는 93%에 짧게). 줄리아처럼 **초반 35%에 한 번 더** 넣는 경우도 있다 ("과학자들은 현실적인 가능성부터 따져 보았죠").
- 형식: **"하지만 학계는 ~라고 말했습니다" → 근거 2~3개 → "하지만 ~는 어떤 식으로도 설명되지 않았죠"**. 반론을 공정하게 소개하되, 마지막 말은 늘 '풀리지 않은 부분'이 한다.
- 전문가·기관 이름을 붙인다 (덕성여대 교수, 전문가 분석, 정부 기관).
- 우리 규칙: 반론은 **확인된 사실**로 쓰고 출처를 남긴다. 반론의 빈틈도 **확인된 사실**이어야 한다 (예: "그 지역에 그 새가 살지 않는다"는 말은 서식지 자료로 확인한다).

### 1-8. 끝맺는 방식

- 롱폼 8편 모두 **"기묘한 밤이었습니다."**로 끝난다 (시그니처). 구독 요청은 없다.
- 끝 직전 공식: **"~의 정체는 현재까지도 밝혀지지 않고 있습니다" + "과연 ~은 무엇이었을까요?" + 시적인 한 줄**.
- 쇼츠는 시그니처도 없이 **장면 한가운데서 뚝 끊긴다** (예: 츠치노코 쇼츠는 고문헌 인용 중간에서, 비행기 쇼츠는 "계기판이 거꾸로 돌아가고 있었다"에서 끝난다). 다음이 궁금해서 다시 보거나 롱폼을 찾게 된다.

### 1-9. 제목과 썸네일 공식

**롱폼 제목** = `[범위·시간 수식어] + [~되는/~했던] + [정체불명의·기이한·충격적인] + [대상 별칭] + [분류]`
- 패턴 예: "전세계 곳곳에서 끊임없이 목격되는 정체불명의 나방 인간 [미스터리]" / "실제 역사서에 남겨져 있는 한반도 거인의 기록들 [미스터리]"
- 자주 쓰는 말: '현재까지도', '실제', '충격적인', '정체불명의', '숨겨진 이야기들', 숫자(239명, 3000m, 12000년).
- 분류 꼬리표: [미스터리] [사건사고] [괴담] [자연] [리뷰] [합본], 합본은 "| N월의 몰아보기".

**쇼츠 제목** = 꼬리표 없는 명사형 한 줄 (25자 안팎)
- `[시대/장소]에서 [발견/포착/촬영/목격]된 ['고유 이름' 또는 정체불명의 ○○]`
- 예: "19세기 영국에서 발견된 '악마의 발자국'", "미국 요세미티 국립공원 CCTV에 포착된 정체불명의 괴생명체"

**썸네일** (채널 동영상 탭 화면에서 직접 확인):
- 아래쪽에 굵은 2줄 글씨. **1줄은 흰색, 2줄은 빨간색**이고 검은 테두리를 두른다.
- 이상한 부분을 가리키는 **빨간 화살표**를 넣는다.
- 가끔 위쪽에 노란 글씨로 따옴표 증언이나 장면 묘사를 넣는다.
- 썸네일 글씨는 제목과 다르게, 더 짧고 세게 쓴다 (예: "조선시대 가장 기괴했던 실화 / ○○ 집안 악귀 빙의 사건").

## 2. 우리 파이프라인에 적용 — 대본 규칙

### 2-1. 공통 규칙
- 한 문장은 **최대 40음절** (자막 2줄, 약 7초). 쇼츠 훅 문장은 **15음절 이하**.
- 한 문장에 정보 하나 (사람·시간·사물 중 하나).
- 어미 비율 목표: ~습니다(현재형 진행 포함) 55%, ~죠 20%, ~는데요 20%, 질문 5% 이하. **같은 어미가 3번 연속 나오지 않게** 한다.
- 확실한 정도에 따라 말을 바꾼다:
  - **확인된 사실** (날짜·장소·사망자 수·기관 발표, 출처 있음): "~했습니다"
  - **증언** (목격자가 말한 것): "~라고 말했습니다", "~를 봤다고 증언했죠"
  - **주장·소문** (확인 안 됨): "~라고 주장했습니다", "~라는 소문이 돌았다고 합니다"
  - **재현 화면** (신문, 증언 재구성): 화면에 '재현' 또는 '증언 재구성' 표시
- '[단어]' 노란 강조는 **문장마다 하나 이하**, 쇼츠 한 편에 8~10개.
- 충격 효과(punch zoom, glitch)는 **①훅 ②참사·반전 ③마지막 미스터리 한 줄**, 이렇게 세 곳에만 쓴다.

### 2-2. 훅 템플릿 (우리 문장 예시)
| 유형 | 템플릿 | 예시 |
|---|---|---|
| A. 날짜·장소 콜드오픈 (기묘한 밤 기본) | "[년 월 일], [장소]. [평범한 행동]." | "1955년 8월 21일, 미국 켄터키의 한 농가. 저녁 식사가 막 끝난 참이었습니다." |
| B. 화면 지시 | "이 [사진] 속, [어디]를 보세요." | "이 사진 오른쪽 위. [흐릿한 형체]가 보이십니까?" |
| C. 결과부터 | "[숫자·결과]. 그런데 ~" | "[46명]이 숨진 다리. 그 위에 무언가가 앉아 있었다고 합니다." |
| D. 증언 인용 | "“[짧은 1인칭 인용]” — [누가] 남긴 말입니다." | "“그런 눈은 처음 봤어요.” 1966년, 한 여성이 경찰에 남긴 말입니다." |
| E. 한국 연결 | "[한국 장소]와 관련된 [주장]이 있습니다." | "한국전쟁 중, 철원 상공에서 [미군이 UFO와 교전했다]는 증언이 있습니다." |
| F. 은폐 | "[기관]은 [무엇]을 [몇 년] 동안 공개하지 않았습니다." | "미 공군은 이 보고서를 [17년] 동안 기밀로 묶어 두었습니다." |

금지: "안녕하세요", "오늘은 ~에 대해 알아보겠습니다", "여러분 혹시 ~아시나요?", 채널명으로 시작하기.

### 2-3. 55~60초 쇼츠 구조 템플릿 (대사 290~330음절, 문장 12~15개)

| 시간 | 구간 | 내용 | 연출 |
|---|---|---|---|
| 0–3초 | ① 훅 | 훅 템플릿 A~F 중 하나. 붉은 눈·이상한 형체·숫자 | 충격 효과 1 (punch zoom) |
| 3–12초 | ② 무대 | 날짜·장소·인물·평범한 상황 (재연, 현재형) | 사진 + 위치 스탬프 |
| 12–28초 | ③ 첫 목격 | 감각 하나씩 → 1인칭 인용 한 줄 → "~는데요" | 증언 자막에 따옴표 |
| 28–40초 | ④ 키우기 | 다른 목격자, 같은 시각 / 이름 붙음 / 숫자 | 문서·신문 사진 ('재현' 표시) |
| 40–50초 | ⑤ 반전·참사 | "그런데 그날 ~" 참사나 은폐 사실 (확인된 사실) | 충격 효과 2 (glitch) |
| 50–56초 | ⑥ 반론 한 줄 + 빈틈 | "학계는 ~라고 봅니다. 하지만 ~는 설명되지 않았죠." | 차분하게 |
| 56–60초 | ⑦ 고리 결말 | 질문 하나, 또는 **첫 문장으로 되돌아가는 한 줄** | 충격 효과 3 + 404 글리치 끝 화면 |

- **반복 재생 고리 (loop)**: 마지막 문장이 첫 문장의 앞부분이 되게 쓴다. 예) 끝 "…그리고 오늘도, 누군가는 그 [붉은 눈]을 봤다고 말합니다." → 처음 "이 붉은 눈을 봤다는 사람들이 있습니다."
- **말로 하는 구독 요청은 뺀다** (#001의 "구독하고, 다음 파일을 열어 보세요"는 고리를 끊는다). 끝 화면의 '다음 파일 예고' 글자와 고정 댓글이 그 역할을 맡는다.
- 이야기 전체를 다 말하지 않는다. 기묘한 밤처럼 **해답 직전에서 멈추고**, 롱폼이 생기면 "전체 파일" 링크로 보낸다.

### 2-4. 8~12분 롱폼 구조 템플릿 (기묘한 밤 공식 기준, 10분 = 약 3,000~3,300음절)

| 비율 | 시간(10분 기준) | 구간 | 핵심 장치 |
|---|---|---|---|
| 0–9% | 0:00–0:55 | **콜드오픈** — 첫 목격을 재연 + 1인칭 인용, 결정적인 순간에 끊음 | 날짜·장소 첫 문장, "쿵" 하는 효과음 |
| 9–11% | 0:55–1:05 | 타이틀 — "파일404 · #00N ○○" 글리치 (10초 이하, 기묘한 밤처럼 1분은 쓰지 않는다) | |
| 11–28% | 1:05–2:50 | **두 번째 목격** — "그러나 ~는 이제 막 시작된 것이나 다름없었습니다" → 같은 날 다른 목격자 → **이름이 붙음** | 열린 고리 1 |
| 28–38% | 2:50–3:50 | **퍼짐** — 목격담 몽타주 ("~보았다. ~했다. ~노려보았다.") + 숫자 | 짧은 '-다' 문장 3개 |
| 38–48% | 3:50–4:50 | **참사·은폐와 연결** — "그런데 ~그날" (확인된 사실과 출처) | 충격 효과, 열린 고리 2 ("자취를 감춥니다. 그런데…") |
| 48–63% | 4:50–6:20 | **넓히기** — 세계 곳곳 / 다른 시대 / 비슷한 사례 2~3개 (증언 수준은 "~라고 합니다") | 지도, 연표 |
| 63–68% | 6:20–6:50 | **해석들** — 초자연·외계·음모론 (모두 "~라고 주장합니다") | |
| 68–78% | 6:50–7:50 | **과학 반론 → 빈틈** — "하지만 학계는 ~" 근거 2~3개 → "하지만 ~는 설명되지 않았죠" | 차분한 음악 |
| 78–93% | 7:50–9:20 | **현대 목격** — "~잊혀져 가는 듯 보였죠. 그러던 20XX년, …" 사진·보도·제보 인용 | 열린 고리 3 |
| 93–100% | 9:20–10:00 | **결말** — "아무도 모릅니다. 확실한 것은 ~" → 질문 1~2개 → 시적인 한 줄 → **시그니처 "파일404, 기록을 닫습니다."** | 404 글리치 끝 화면 |

- 챕터(설명란 타임스탬프): 00:00 첫 번째 목격 / 01:05 두 번째 밤 / 02:50 이름이 붙다 / 03:50 그날의 참사 / 04:50 세계 곳곳의 목격 / 06:50 과학의 설명 / 07:50 다시 나타나다 / 09:20 남은 질문
- **"하지만 가장 이상한 것은 따로 있었습니다"** 같은 예고 문장은 롱폼 한 편에 2번까지만 쓴다.
- 1인칭 인용은 3~5번 넣는다. 인용 목소리는 같은 TTS로 하되, 화면에 따옴표와 '증언 재구성' 표시를 한다.
- 합본 전략: 같은 주제의 파일 4~6개가 쌓이면 "파일404 기록 모음 | 미군이 숨긴 괴물들" 같은 30~40분 합본을 만든다. 기묘한 밤에서 조회수가 가장 높은 형식이다.

### 2-5. 제목 템플릿 (우리용)
- 쇼츠: `[시대·장소]에서 [포착·목격·발견]된 '[별칭]'` / `[숫자] + [결과]` (예: "다리가 무너지기 직전 목격된 '붉은 눈의 나방 인간'", "17년간 기밀이었던 미 공군의 괴생물체 보고서")
- 롱폼: `[수식절] + 정체불명의/기이한 + [대상] [미스터리]` (예: "재앙이 일어나기 직전마다 목격되었다는 정체불명의 나방 인간 [미스터리]")
- 시리즈 표시는 제목에 넣지 않고 화면 띠("파일404 · #001")와 설명란 첫 줄에 넣는다. 제목 글자 수를 아끼기 위해서다.
- 해시태그는 설명란에 3~5개만: #미스터리 #미확인생물 #UFO #실화 #파일404. 미스터리튜브처럼 제목에 해시태그를 늘어놓지 않는다.

### 2-6. 설명란과 고정 댓글
설명란:
```
파일404 · #00N [대상 이름]
[한 줄 요약: 언제, 어디서, 무엇이] — 확인된 사실과 전해지는 이야기를 구분해 정리했습니다.

▶ 확인된 사실의 출처
- [기관/신문/보고서 이름, 연도, 링크]
▶ 사진 출처 (라이선스)
- (output/<id>/사진출처.txt 내용을 그대로)
※ '재현' 표시 화면은 실제 기록이 아니라 다시 만든 화면입니다.

#미스터리 #[주제] #파일404
```
고정 댓글 (구독 요청 대신 참여 유도 + 다음 파일 예고):
- "여러분은 이것이 [가설 A]라고 보시나요, [가설 B]라고 보시나요? / 다음 파일: #00N+1 [제목 미리보기]"
- Top5s 쇼츠가 끝에 "여러분 생각은?"을 붙이는 것처럼 댓글을 부르는 질문이다. 우리는 **영상 속 말로 하지 않고 고정 댓글로** 한다.
