# 유튜브 예약 업로드 설정 (upload.py · bot.py)

렌더가 끝난 영상을 YouTube Data API v3 로 올리고 **비공개 + 공개 예약**으로 걸어 둔다.
공개는 유튜브가 그 시각에 하므로 맥이 꺼져 있어도 된다. 업로드 버튼(`--yes`, 봇의 [올리기])은 항상 사용자가 직접 누른다.

비밀 파일은 모두 git 에서 빠져 있다 (`.gitignore`): `.secrets/` (구글 클라이언트·로그인 토큰), `.env` (설정값).

---

## 1. 구글 클라우드 프로젝트 (처음 한 번)

메뉴 이름이 바뀌었다: 'OAuth 동의 화면'은 이제 **Google 인증 플랫폼(Google Auth Platform)** 이다.
주소를 바로 열어도 된다 (위쪽에서 프로젝트가 맞게 골라져 있는지 확인).

1. https://console.cloud.google.com/projectcreate → 이름 `file404-upload` → **만들기** → 알림에서 **프로젝트 선택**
2. https://console.cloud.google.com/apis/library/youtube.googleapis.com → **사용** (Enable)
3. https://console.cloud.google.com/auth/overview → **시작하기** (Get started)
   - 앱 정보: 앱 이름 `File404 Upload`, 사용자 지원 이메일 = 내 이메일
   - 대상: **외부** (External)
   - 연락처 정보: 내 이메일 → 정책 동의 → **만들기**
4. https://console.cloud.google.com/auth/audience (**대상**)
   - **테스트 사용자 → + Add users** → 채널을 관리하는 구글 계정 추가 → 저장
   - ⚠️ '테스트' 상태로 두면 로그인이 **7일마다 만료**된다. 매주 `auth` 를 다시 하기 싫으면 같은 화면의 **앱 게시**(Publish app) → 프로덕션.
     개인용이라 구글 검증 없이도 로그인할 때 '확인되지 않은 앱' 경고만 뜨고 쓸 수 있다
   - 데이터 액세스(범위)는 비워 둬도 된다 (upload.py 가 로그인할 때 요청한다)
5. https://console.cloud.google.com/auth/clients (**클라이언트**) → **+ 클라이언트 만들기** (Create client)
   - 애플리케이션 유형: **데스크톱 앱**, 이름 아무거나 → **만들기**
   - 뜨는 창에서 **JSON 다운로드** (창을 닫았으면 목록에서 클라이언트 클릭 → 오른쪽 '클라이언트 보안 비밀번호' 옆 다운로드 아이콘)
6. 받은 파일을 프로젝트 폴더의 `.secrets/client_secret.json` 으로 저장
   ```
   mkdir -p .secrets && mv ~/Downloads/client_secret_*.json .secrets/client_secret.json
   ```

## 2. 채널 연결

```
./.venv/bin/python upload.py auth
```
브라우저가 열리면 **유튜브 채널 주인 계정**(구글 클라우드를 만든 계정과 다를 수 있다. 파일404 는 whoskb94) → **파일404 채널(브랜드 계정)** 을 고른다. 그 계정이 1-4 의 테스트 사용자에 들어 있어야 한다. '확인되지 않은 앱' 이 뜨면 *고급 → 이동*.
끝나면 `연결된 채널: 파일404` 처럼 나와야 한다. 다른 채널이 나오면 `.secrets/youtube_token.json` 을 지우고 다시 `auth`.

## 3. API 심사 (중요)

2020년 7월 이후 만든 API 프로젝트는 **심사(감사)를 통과하기 전까지 올린 영상이 모두 '비공개'로 잠긴다.**
잠긴 영상은 예약 공개도 되지 않고, 나중에 공개로 바꿀 수도 없다 (다시 올려야 한다).

- 신청: https://support.google.com/youtube/contact/yt_api_form
- 신청서에 필요한 파일: `output/api_audit/` (아키텍처·사용자 흐름 그림, 약관 PDF)
- 공개 페이지 (원본은 `site/`, 올린 곳은 github.com/junsoom/file404-site):
  홈 https://junsoom.github.io/file404-site/ · 개인정보처리방침 …/privacy.html · 약관 …/terms.html
  같은 주소를 Google 인증 플랫폼 → 브랜딩에도 넣는다. 페이지를 고치면 site/ 를 고친 뒤 그 저장소에 다시 올린다
  (용도: 내 채널 하나에 직접 만든 영상을 예약 업로드하는 개인 도구)
- 통과 메일을 받으면 프로젝트 폴더에 `.env` 를 만들고:
  ```
  YT_AUDITED=1
  ```
- 그 전까지 upload.py 와 봇은 미리보기마다 ⚠️ 경고를 띄운다. 심사 전에는 **Studio 에서 직접 올리는 것**을 권한다.

## 4. 할당량·제한

- 하루 10,000 단위, 업로드 한 편에 약 1,600 단위 → **하루 약 6편**. 넘으면 "오늘 유튜브 업로드 한도" 메시지 → 다음 날 다시
- 롱폼 썸네일은 API 로 같이 올린다 (`output/<id>/썸네일_*.jpg` 의 첫 번째, 또는 스펙 `upload.thumbnail`).
  **채널 전화번호 인증**이 안 돼 있으면 썸네일만 실패하고, 영상은 올라간다 → Studio 에서 직접
- 쇼츠 썸네일은 API 로 바꿀 수 없다 → 유튜브 앱에서 장면을 고른다 (`업로드_안내.md` 의 추천 초)
- 고정 댓글, 롱폼 최종 화면, 쇼츠 '관련 동영상' 연결은 API 로 안 되므로 `업로드_안내.md` 를 보고 직접

## 5. 명령줄로 올리기

```
./.venv/bin/python upload.py list                                        # ⬜ 안 올림 / ✅ 올림 (링크·공개 시각)
./.venv/bin/python upload.py dyatlov_short --at "2026-11-06 19:00"        # 미리보기만
./.venv/bin/python upload.py dyatlov_short --at "2026-11-06 19:00" --yes  # 올리고 그 시각에 공개 예약
./.venv/bin/python upload.py rosie_short bigfoot_short gevaudan_short --at "2026-11-07 19:00" --every 1 --yes
                                                                         # 하루 간격으로 7·8·9일 19시
```
- 시각은 한국 시간, 지금부터 30분 뒤 이후만 된다. `--at` 을 빼면 비공개로만 올린다
- 제목은 스펙 `upload.titles` 의 첫 번째(추천), 설명·태그는 `업로드_안내.md` 와 같다
- 올린 기록은 `업로드_기록.json`. 같은 번호는 두 번 올리지 않는다

## 6. 텔레그램 봇 (폰에서 올리기)

1. 텔레그램에서 **@BotFather** → `/newbot` → 이름·아이디 정하기 → 받은 **토큰**을 `.env` 에:
   ```
   TELEGRAM_TOKEN=123456789:AA...
   ```
2. 맥에서 봇 켜기:
   ```
   caffeinate -i -s ./.venv/bin/python bot.py
   ```
3. 폰에서 내 봇에게 `/id` → 나온 번호를 `.env` 에 넣고 봇을 껐다 켠다:
   ```
   TELEGRAM_CHAT_ID=987654321
   ```
   이 번호의 채팅방에서 온 명령만 받는다 (다른 사람이 봇을 찾아도 `/id` 말고는 반응하지 않는다).
4. 명령
   - `/list` — 올릴 수 있는 영상
   - `/up dyatlov_short 2026-11-06 19:00` — 미리보기 → **[올리기]** 버튼을 눌러야 올라간다 (10분 안에)
   - `/up rosie_short bigfoot_short 2026-11-07 19:00 1` — 여러 편, 끝 숫자는 간격(일)
   - `/log` — 올린 기록
5. 봇은 맥에서 돈다: 맥이 켜져 있고 인터넷에 연결돼 있어야 명령을 받는다 (예약 공개 자체는 유튜브가 한다).
   로그인이 만료되면 봇이 "upload.py auth" 를 알려 준다 → 맥에서 2번을 다시.
